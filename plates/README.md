# Hermes Switch Plates

DXF files for the Hermes switch plate, in millimetres. Outline: 78.2 × 139.6 mm.

| File | Solder PCB (Hermes only) | Hot-swap PCB (Hermes and Hermes SP) |
|---|---|---|
| [`Hermes Switch Plate HS 1.0.DXF`](Hermes%20Switch%20Plate%20HS%201.0.DXF) | ✗ | ✓ |
| [`Hermes Switch Plate Solder.DXF`](Hermes%20Switch%20Plate%20Solder.DXF) | ✓ | ✓ |

> **Note:** Hermes and Hermes SP (southpaw) use the **same plate files**. There are no separate southpaw plates.
>
> - The **solder plate** fits every Hermes PCB: solder and hot-swap, standard and southpaw.
> - The **hot-swap plate** fits hot-swap PCBs only. It does **not** fit the solder PCB.
> - The Hermes SP is hot-swap only; there is no southpaw solder PCB.
